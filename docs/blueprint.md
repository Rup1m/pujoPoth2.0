# **App Name**: PujoPath Navigator

## Core Features:

- Geolocation Request: Request the user's location via the browser's native API.
- Map Initialization: Initialize the Google Maps view centered on the user's location, using a tool to verify accurate location before rendering.
- Error Handling: Display a user-friendly message if location access is denied, with a retry option.

## Style Guidelines:

- Primary color: Vibrant saffron (#FF9933) to reflect the festive spirit and energy of Durga Puja.
- Background color: Light beige (#F5F5DC) to provide a warm and inviting feel.
- Accent color: Deep blue (#0047AB) to symbolize the divine and create contrast.
- Body and headline font: 'PT Sans', a humanist sans-serif for a modern and warm aesthetic, and great legibility.
- Full-screen map view with minimal UI elements for an immersive experience.
