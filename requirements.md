# 🔒 Non-Negotiable Product Requirements — Pujoপথ

## 🎯 Product Philosophy

1. User-centric above everything else
2. Simple, practical, real-world utility
3. Feature-first execution
4. No unnecessary complexity
5. No bloated "multimillion-dollar app" thinking
6. Build only what genuinely improves user experience
7. Robust MVP instead of feature overload
8. Utility over gimmicks
---
# 📱 Mobile-First Requirements

9. 100% mobile-centric application
10. Optimized primarily for Android & iOS smartphones
11. Desktop experience not a priority
12. Must work smoothly across all screen sizes
13. Must work on low-end devices as well as flagship phones
14. Touch-first UX everywhere
15. Lightweight rendering and interactions
